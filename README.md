# FLPR Premium v2.0 Stable

Production-ready static Netlify/GitHub package.

## Stability changes
- Native browser hash links for every main route.
- One hashchange router controls page rendering.
- JavaScript click delegation is limited to player cards only.
- Mobile drawer closes after a native navigation click without cancelling navigation.
- Landing layout from v1.8 is preserved.

Deploy the files at repository root. Netlify base directory and publish directory should remain empty or use `.`.
