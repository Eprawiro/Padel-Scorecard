# FLPR Premium v1.0 — Player Guide

- **Home** shows the latest verified podium, current top 10, and award preview.
- **Tournament Center** shows verified summaries, records, comparison, and champion history.
- **Full Scoreboard** contains the complete workbook-derived player table.
- **Ranking** adds rating, win rate, consistency, momentum, handicap, and movement.
- **Player Scorecards** opens the full player directory first. Select a player to view performance charts, field comparison, partner/opponent analysis, coaching priorities, and achievements.
- **Statistics** contains leaderboards. Tap the circular **i** icon for the definition, calculation, and interpretation of each metric.
- **Hall of Fame** contains verified champions and workbook awards.

Metrics should be interpreted together with match count and data reliability. Provisional players have smaller samples and can move more quickly.
