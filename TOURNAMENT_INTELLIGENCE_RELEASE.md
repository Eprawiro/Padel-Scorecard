# FLPR Tournament Intelligence

## Included
- Verified tournament count
- Champion diversity
- Championship title leader
- Average tournament field
- Closest non-negative point finish
- Official tie-break event count
- Event-by-event finish profiles:
  - Official Tie-break
  - Photo Finish
  - Close Finish
  - Clear Win
- Interactive information dialogs with transparent formulas

## Data protection
- Uses official final positions and verified tournament fields.
- Does not modify tournament data, ranking, rating, confidence, or handicap.
- Internal UUIDs remain available for database joins and duplicate detection.
